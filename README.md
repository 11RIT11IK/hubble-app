# Hubble — Cavli Wireless Full-Stack Assessment

A full-stack project built for the Cavli Wireless Web Developer assessment, sharing a single database across a 3D product landing page, a Google Meet consultation booking flow, and an automated 3NF-normalized exhibitor scraper[cite: 4, 5, 6].

## 🛠️ Tech Stack
- **Frontend & API:** Next.js (App Router), TypeScript, Tailwind CSS[cite: 4, 6]
- **3D Rendering:** `@google/model-viewer`
- **Database & ORM:** MySQL, Prisma ORM
- **Integrations:** Google Calendar API (`google-api-nodejs-client`), Nodemailer (Gmail SMTP with asynchronous execution via `after()`)
